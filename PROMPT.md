# Prompt used to create Grab Stuff

Create a browser extension for X/Twitter that works in Firefox, Safari, Brave, and Chrome. When the extension is enabled, automatically capture posts as they appear in a timeline. Save each post only once, using its status ID to deduplicate across scrolling, repeat visits, and tabs. Let the user choose between capturing posts only and capturing both posts and replies. Allow the user to upload a list of X handles; when a list is present, capture only posts by those handles. Show the controls and saved posts in a sidebar that opens by default on X pages. Let the user download the saved collection as JSON or CSV and clear it. Keep captured data in local browser storage. Add a README with build, installation, usage, and browser compatibility instructions.
